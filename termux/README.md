## step-termux

### Instructions

1. Install Termux from either [F-Droid](https://f-droid.org/en/packages/com.termux/) or [Google Play](https://play.google.com/store/apps/details?id=com.termux)
2. Copy the below **install** command
3. Open Termux
4. hold the Termux terminal background for 1-2 seconds and let go. You should see a **Paste** button appear.
5. tap the **Paste** button
6. press the **Enter** key on your touch keyboard

### install

```bash
curl --proto '=https' --tlsv1.2 -sSf https://raw.githubusercontent.com/duhdugg/step/refs/heads/termux/termux/install-step-termux.sh | bash
```

### uninstall

```bash
curl --proto '=https' --tlsv1.2 -sSf https://raw.githubusercontent.com/duhdugg/step/refs/heads/termux/termux/uninstall-step-from-termux.sh | bash
```
